# ALIVE Codex 3.3.0-alpha.3

This private-alpha release is gated for the Codex adapter only.

## Changed

- Index generation preserves multiline session tags and emits one
  JSON-compatible YAML/JSON structure with a shared generation marker. Dynamic
  scalar types remain strings, and a failed second replacement restores the
  previous pair.
- Codex startup no longer injects the full world index. It renders only the
  cached `_orientation.json` projection, capped at 8,192 bytes and three
  displayed recommendations.
- Deterministic, read-only recommendations identify overdue dates, expired
  relative dates, and task/status contradictions. At most nine recommendations
  are stored.
- Explicit save/project refresh regenerates the index and orientation, then
  verifies the strict schema and full source-index digest identity before
  accepting the bounded cache.
- Doctor checks index/orientation health and follows registered Codex hook
  source and executed-helper dependencies when enforcing the no-full-index
  startup boundary.
- Malformed task sources produce deterministic path-only health notices.
  Archived walnuts and `01_Archive` subtrees are excluded from current-action
  recommendations.

## Verified on 2026-07-25

- The full Codex unit suite passed.
- The locked MCP suite passed, including pinned Inspector contract snapshots.
- Shared-runtime drift verification returned `{"divergent": []}`.
- Install, reinstall, upgrade, doctor, marketplace build, uninstall, and
  two-process walnut recovery lifecycle tests passed.
- Earlier candidate evidence used a backed-up real local world and showed that
  index/orientation generation did not change walnut/kernel source files. The
  final strict-schema hardening was verified only against temporary test worlds;
  this fix did not modify `MyWorld`.

## Limits

- Lifecycle hooks are best-effort assistance and do not guarantee background
  refresh.
- Explicit save/project is the guaranteed refresh path.
- Recommendations surface evidence for review. No task is automatically
  completed, dropped, deleted, or rewritten.
- Index and orientation files are generated and stored locally. When trusted
  Codex hooks run, the bounded rendered orientation enters
  `additionalContext` and is sent to the configured model provider unless that
  provider is local.
- Claude adapter lifecycle behavior was not approved or validated for this
  release. Its hook files remain byte-identical to the legacy baseline,
  including existing full-index/context injection behavior. The shared index
  serialization fix applies, but default shared generation does not create
  Codex orientation. Cross-runtime parity is not claimed.

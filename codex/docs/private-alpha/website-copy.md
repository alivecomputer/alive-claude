## Limitations disclosure

**Heading:** What private alpha means

ALIVE does not guarantee an automatic save on every crash, forced exit, hosted
tool call, or disabled-hook session. Codex hooks are trust-gated, user-
disableable, and concurrent; they are lifecycle assistance, not a security
boundary. Explicit save is the supported persistence path.

The current alpha is tested on macOS with `codex-cli 0.146.0-alpha.3.1`.
Windows, Linux, offline installation, public marketplace approval, and the
hosted walnut.world product surfaces are not yet supported claims.

Install ALIVE v3.3 in a Codex profile that has no other ALIVE product enabled.
The v3.3 and v4 plugins have different runtime and persistence semantics and
are not supported together.

## Privacy copy

**Heading:** Your world stays a folder

ALIVE stores your world as local files. The packaged MCP server does not phone
home. Installing MCP downloads locked Python dependencies. When you ask Codex
to read a walnut, the context you select is sent to your configured model
provider under that provider's data controls. If you trust ALIVE's Codex
lifecycle hooks, their bounded startup orientation is added to
`additionalContext` and is also sent to that provider unless your configured
model runs locally. Publishing is always a separate, explicit projection—not
automatic exposure of a private walnut.

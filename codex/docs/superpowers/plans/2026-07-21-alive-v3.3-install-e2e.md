# ALIVE v3.3 Codex Install and E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove native install, upgrade, uninstall, and real cross-session walnut recovery in isolated Codex environments.

**Architecture:** Shell entry points wrap official Codex marketplace commands and emit machine-readable evidence. Tests use a fresh `CODEX_HOME`, a built marketplace, and a copied walnut; no global hooks merge occurs.

**Tech Stack:** Bash, Python stdlib, Codex CLI 0.145.0-alpha.18, temporary directories.

## Global Constraints

- Preserve unrelated Codex configuration and all world data.
- Treat inability to run a model-backed session as BLOCKED, never PASS.
- Hash the source walnut before and after E2E proof.

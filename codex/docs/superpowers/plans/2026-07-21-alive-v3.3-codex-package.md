# ALIVE v3.3 Codex Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained ALIVE v3.3 Codex plugin artifact that preserves the v3 walnut model.

**Architecture:** The private-alpha package carries a pinned v3.3 Codex runtime
snapshot. The allowlisted sync boundary is deliberately limited to the approved
index serializer and orientation projection; broader Claude/Codex runtime
convergence requires separate review and does not imply lifecycle parity.
Codex-specific manifest, skills, hooks, launchers, and release scripts live in
`codex/`. Tests validate the installed artifact rather than relying on
source-tree paths.

**Tech Stack:** Bash 3.2+, Python 3.10–3.13, Python stdlib tests, Codex CLI plugin marketplace.

## Global Constraints

- Preserve the existing ALIVE architecture and shared walnut format.
- Do not depend on `exitplatforms` or v4 schemas.
- MCP is read-only for the private alpha.
- Explicit save is guaranteed; lifecycle hook behavior is documented as best-effort.
- Never delete or modify a user's world during install, upgrade, or uninstall.
